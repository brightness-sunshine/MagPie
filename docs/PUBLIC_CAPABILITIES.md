# Public v1 Capabilities

## Included

- X bookmark ingest prototype
- Local SQLite store
- JSONL compatibility import
- Raw snapshot layout
- Normalized bookmark schema
- Dedupe/upsert by stable id
- Full-text search
- Lightweight grouping/themes
- Folder-first onboarding
- Markdown export
- Telegram-style payload generation

## Excluded from public repo

- Real bookmark data
- Raw X API responses
- SQLite runtime database
- Secrets / tokens
- Personal sessions or trajectories

## Not built yet

- Native Telegram callback router
- Browser bookmark import
- Persistent user-edited folder assignments
- Local web UI
- Multi-source connectors
- Hosted SaaS / multi-user auth
